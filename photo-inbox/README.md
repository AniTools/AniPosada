# Photo inbox

Drop photos here, then run `./publish.sh` (or `npm run photos`).

- Photos placed directly in this folder are added to the gallery (no album).
- Photos inside a sub-folder go to the album with that folder's name,
  e.g. `photo-inbox/Sunset Vibes/` or a new one like `photo-inbox/River Session/`.

Photos are resized, converted to WebP, added to the gallery and removed from
this folder. Edit their descriptions any time in /keystatic → Gallery photos.
